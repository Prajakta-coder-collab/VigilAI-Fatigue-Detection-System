# VigilAI — AI-Powered Multimodal Fatigue Detection System

## Overview
VigilAI is an AI-powered multimodal fatigue monitoring dashboard designed for students and employees. The system provides fatigue analytics, session monitoring, fatigue alerts, and AI-inspired monitoring workflows through an interactive dashboard.

## Features
- Real-time fatigue monitoring
- Fatigue score visualization
- Session tracking dashboard
- Interactive AI-style UI
- Fatigue history analytics
- Alert and recommendation system
- Responsive dark-themed design

## Tech Stack
- React
- Python
- REST APIs
- Dashboard Analytics
